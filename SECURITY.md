# Security Policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of opening
a public issue. Include a minimal reproducer, affected versions and expected
impact when possible.

PDF files are untrusted input. Avoid sharing confidential documents in public
issues, and keep Tesseract, Ghostscript, OCRmyPDF and Python dependencies up to
date in deployments that process files from third parties.
